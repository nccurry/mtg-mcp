# Ordinary Plan Template

Use this repository-owned template for ordinary durable implementation plans.
Current code, tests, configuration, `AGENTS.md`, and human docs remain
authoritative when a plan becomes stale.

## Ordinary Plans

Copy [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) into
`docs/llms/plans/<feature-slug>.md` for work that benefits from durable context
but does not need requirements and architecture documents.
